# DineReserve Frontend

A premium, high-performance customer interface for the DineReserve ecosystem.

## 🌟 Visual Excellence
- **Premium Aesthetics:** Dark-themed UI with emerald accents and glassmorphism.
- **Dynamic Animations:** Smooth transitions powered by Framer Motion.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop.
- **Micro-interactions:** Interactive floor plans and real-time state updates.

## 🛠 Tech Stack
- **Framework:** React 18+ with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Networking:** Axios & Socket.io-client

## 📦 Installation
1. Clone the repository.
2. Navigate to `/frontend`.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```

## 🏗 Key Components
- `App.tsx`: Main entry and landing page.
- `/src/components`: Reusable UI elements.
- `/src/hooks`: Custom React hooks for state and sockets.
- `/src/services`: API and socket service layers.

## 🎨 Design System
- **Colors:** Deep Obsidian (`#0c0a09`), Emerald Primary (`#22c55e`).
- **Typography:** Inter for maximum readability.
- **Depth:** Subtle borders and backdrop blurs for a premium "Glass" feel.
